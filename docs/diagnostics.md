# 서버 점검 (점검 키 + /api/diag)

Claude 같은 도우미가 NAS 에서 돌고 있는 알피를 **읽기 전용**으로 직접 점검할 수 있게 하는 기능입니다.
비밀번호나 2단계 인증 코드를 알려 줄 필요가 없습니다.

## 쓰는 법
1. https://alphy.devsean.me/settings → "점검 키 (읽기 전용)" → 이름·기간(1·7·30일) 정하고 **점검 키 만들기**
2. 나온 키(`alphy_diag_...`)를 복사해 Claude 스레드에 붙여 넣기 (한 번만 보임)
3. 점검이 끝나면 같은 화면에서 **폐기**

## 키로 할 수 있는 것 / 없는 것
- 됨: `/api/diag/*` 만 (`Authorization: Bearer <키>`)
  - `GET /api/diag` — 배포된 커밋·빌드 시각·가동 시간, 설정이 되어 있는지 여부(값은 없음), 저장된 전략, 캐시 요약
  - `GET /api/diag/data?tickers=069500&start=2024-01-01&end=2026-11-13` — 종목별 시세 범위·빈 구간·캐시 상태 (네이버·CSV·가상만)
  - `POST /api/diag/backtest` — `{ "strategy": "저장한 전략 이름", "tickers": ["069500"], "start": "...", "end": "...", "cash": 10000000, "monthly": 0 }` 로 서버에서 다시 돌려 거래·마지막 상태 확인
- 안 됨: 화면, 설정 보기·변경, 주문, 잔고, 전략 저장, 한국투자증권 시세. 다른 주소에 키를 보내면 401.
- 직접 작성한 코드 전략은 서버에서 실행하지 않습니다(조건 고르기·적립 분할 매도·기본 전략만).

## 안전장치
- 서버에는 키의 SHA-256 해시만 저장, 최대 5개, 최대 30일
- 마지막 사용 시각·주소가 화면에 보이고, 발급·폐기는 로그인 기록에 남음
- 비밀번호 변경·"모든 기기 로그아웃" 때 모두 폐기
