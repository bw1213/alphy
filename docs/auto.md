# 자동 매매 (1~3단계: 저녁 계산·알림, 아침 자동 주문, 장중 실시간 매도)

화면: `/auto` (상단 메뉴 "자동 매매")

## 지금 되는 것
- **운용 전략**: 보관함 전략(조건 고르기·적립·분할 매도, 관리자는 코드 전략도) 또는 기본 전략을 골라 대상 종목·운용 금액·시작일과 함께 저장. 보관함 전략은 복사해 두므로, 보관함에서 고친 뒤 여기서 다시 저장해야 운용에 반영됩니다. 한 사람에 운용 전략 하나.
- **저녁 계산**: 평일 설정 시각(기본 18:00, 관리자가 화면에서 변경) 이후 하루 한 번, 시작일 다음 거래일부터 오늘 종가까지 전략을 다시 돌려
  - 내일 아침 주문 목록 (전략이 사고팔기로 한 종목만, 실제 계좌 보유 기준. 계좌를 못 읽으면 전략상 보유 기준)
  - 장중 매도 가격과 수량 (적립·분할 매도의 하락 매도·추가 매도 단계 가격, 손절·익절 가격)
  을 만들고 기록합니다. 오늘 시세가 없으면 휴장일로 보고 조용히 건너뜁니다. 모두 실패하면 10분 뒤 다시(하루 3번까지). NAS 가 꺼져 있었다면 그날 자정 전까지 켜지면 계산합니다.
- **아침 자동 주문**: 평일 주문 시각(기본 08:40)에 어제 저녁 계산의 주문을 시장가로 냅니다. 매도 먼저, 현금이 모자라면 매도 체결 뒤(09:01~09:10) 남은 현금만큼 매수. 09:00 이후 3분마다 체결 확인, 마감 시각(기본 10:00)에 미체결 취소 후 결과 알림.
- **장중 실시간 매도** (운용 전략의 "장중 실시간 매도", 기본 켬): 평일 09:00~15:20 동안 15초마다 현재가(한국투자증권 현재가 조회)를 보고, 매도 가격에 닿으면 바로 시장가로 팝니다.
  - 하락 매도: 저녁 계산이 정한 수량 (계좌에 있는 만큼). 한 번에 여러 단계를 지나면 한 주문으로 묶음.
  - 손절(현재가 ≤ 가격)·익절(현재가 ≥ 가격): 그 종목 전부. 그 종목의 다른 가격은 그날 끝.
  - 같은 가격으로는 하루 한 번만. 1분마다 체결 확인, 주문·체결을 텔레그램으로 알림.
  - 운용을 끄거나 긴급 정지하면 감시도 멈춥니다. 실전 계좌면 주문 금액 한도(설정)를 그대로 지킵니다.
- **백테스트의 장중 매도** (백테스트 화면 "장중 매도" 체크, 자동 매매 저녁 계산은 운용 설정을 따름): 손절·익절과 적립 전략의 하락 매도를 그날 저가·고가로 확인해, 닿은 날 그 가격(시가가 이미 넘었으면 시가)에 판 것으로 계산합니다. 같은 날 손절·익절 둘 다 닿으면 손절로 봅니다. 끄면 예전처럼 종가로 확인하고 다음 날 시가에 팝니다.
  - 전략 코드에서는 장 마감 때 `ctx.stops[종목] = [{ below: 가격, qty: 수량, note: "이유" }]` 로 다음 날 장중 매도를 걸 수 있고, 다음 날 `ctx.filled[종목]` 으로 체결을 알 수 있습니다 (`ctx.intraday` 가 true 일 때만).
- **텔레그램 알림**: 관리자가 @BotFather 로 만든 봇 토큰을 한 번 넣고, 각자 "연결 코드"를 봇에게 보내 연결합니다 (웹훅·포트 열기 불필요).
- **계정별 한도** (설정 → 주문 대상 카드 "자동 매매 한도"): 실전 운용 금액 상한, 손실 한도 %(저녁 계산에서 운용 금액 대비 손실이 닿으면 운용을 끄고 알림). 기본 100만 원 / 15%.
- **긴급 정지**: 운용을 끄고 오늘 남은 아침 주문을 취소, 장중 감시도 멈춤.

## 아직 안 되는 것 (다음 단계)
- 매일 계좌 기록·백테스트 비교, 손실 한도를 실제 계좌 평가액으로, 실전 전환 (4단계)
- 미국 주식 주문 (5단계)
- 실제 한국투자증권 모의계좌·텔레그램으로는 아직 확인하지 않았습니다 (장전 동시호가 주문, 체결·취소 응답 필드).

## 저장 위치
- `config/users/<사용자>/auto.json` 운용 전략, `auto-log.json` 계산 기록(최근 60개), `notify.json` 텔레그램 대화방 번호
- `auto-orders.json` 아침 주문 기록, `auto-intraday.json` 장중 매도 기록 (최근 30일)
- `config/auto-state.json` 예약 실행 기록 (같은 날 두 번 돌지 않게)
- 봇 토큰: `config/settings.json` 의 `auto.telegramToken`
