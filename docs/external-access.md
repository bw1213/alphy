# 밖에서 접속하기 — https://alphy.devsean.me

알피에는 한국투자증권 앱키가 저장되고 주문까지 나갈 수 있습니다. 인터넷에 열 때는 아래 순서를 그대로 지켜 주세요.

## 구조

```
휴대폰·회사 PC ──HTTPS(443)──▶ 공유기 ──▶ NAS의 DSM 역방향 프록시 (Let's Encrypt 인증서)
                                              └──HTTP──▶ localhost:3000 (alphy 컨테이너)
```

- 밖으로 여는 포트는 **443**(HTTPS)과 **80**(인증서 발급·갱신용) 두 개뿐입니다.
- **3000(알피), 5000/5001(DSM), 22(SSH)는 공유기에서 열지 않습니다.** DSM 관리 화면은 밖에서 보이지 않게 둡니다.
- 알피는 앱 전체가 로그인 뒤에 있습니다. 로그인하지 않으면 백테스트 화면, 시세 API까지 아무것도 열리지 않습니다.

### 알피 안에 들어 있는 보안 장치

| 장치 | 내용 |
|---|---|
| 전체 로그인 | 로그인 전에는 로그인 화면만 보입니다. API 는 401 |
| 2단계 인증 (선택, **외부 접속 시 꼭 켜기**) | 비밀번호 + 휴대폰 인증 앱 6자리. 설정 → 보안 |
| 로그인 잠금 | 접속 주소별 5번 틀리면 10분 잠금, 전체 30번이면 모두 잠금 |
| 로그인 기록 | 설정 → 보안에 최근 기록(시각·주소·기기). 모르는 접속 확인용 |
| 모든 기기 로그아웃 | 다른 곳에 로그인한 채 두고 왔을 때 |
| 실전 주문 잠금 | 비밀번호와 2단계 인증이 다 털려도, NAS 의 `.env` 에 `KIS_ALLOW_REAL_ORDERS=yes` 가 없으면 실제 돈 주문은 안 나감 |
| 실전 주문 금액 상한 | 1회·하루 합계 상한 (설정 화면) |
| 보안 헤더 | 다른 사이트에 몰래 넣기(iframe) 차단, HSTS, 검색 엔진 노출 차단 |
| 컨테이너 권한 | NAS 일반 사용자 권한, 추가 권한 없음(`cap_drop: ALL`, `no-new-privileges`) |

## 0. 먼저 집 안에서 (포트 열기 전에)

1. [synology.md](synology.md) 대로 `docker/alphy` 폴더에 프로젝트를 만들고 `http://NAS-IP:3000` 이 열리는지 확인
2. 관리자 비밀번호 만들기 — 컨테이너 로그의 설정 코드 필요. **12자 이상, 다른 곳에 안 쓰는 비밀번호**를 권장합니다
3. 설정 → 보안 → **2단계 인증 켜기** (QR 코드를 휴대폰 인증 앱으로 찍고 6자리 확인)
4. NAS 의 IP 를 고정: 공유기 DHCP 설정에서 NAS 를 고정 IP 로 할당 (예: `192.168.0.10`)

비밀번호와 2단계 인증을 만든 **다음에** 포트를 엽니다.

## 1. 도메인 연결 (DNS)

집 인터넷 공인 IP 는 보통 가끔 바뀌므로, Synology DDNS 를 만들고 내 도메인이 그걸 가리키게 합니다.

1. DSM → **제어판 → 외부 액세스 → DDNS → 추가**
   - 서비스 공급자: `Synology`, 호스트 이름: 원하는 이름 (예: `devsean.synology.me`) → 확인
   - 상태가 `정상`이고 외부 주소에 집 공인 IP 가 나오는지 확인
2. `devsean.me` 를 관리하는 곳(가비아, 후이즈, Cloudflare 등)의 DNS 설정에서 레코드 추가
   - 종류 `CNAME`, 이름 `alphy`, 값 `devsean.synology.me` (1번에서 만든 이름)
   - Cloudflare 라면 **프록시(주황 구름)는 끄고** "DNS only" 로 둡니다 (Let's Encrypt 발급이 쉬워짐)
   - 공인 IP 가 고정이면 `A` 레코드로 IP 를 직접 넣어도 됩니다
3. 몇 분 뒤 PC 명령 프롬프트에서 `nslookup alphy.devsean.me` → 집 공인 IP 가 나오면 성공

## 2. 공유기 포트 포워딩

공유기 관리 화면(ipTIME: **고급 설정 → NAT/라우터 관리 → 포트포워드 설정**)에서:

| 이름 | 외부 포트 | 내부 IP | 내부 포트 | 프로토콜 |
|---|---|---|---|---|
| nas-https | 443 | NAS IP (예: 192.168.0.10) | 443 | TCP |
| nas-http | 80 | NAS IP | 80 | TCP |

- 80 은 Let's Encrypt 가 인증서를 발급·갱신(약 2~3개월마다)할 때 확인용으로 씁니다. 알피 화면은 80 으로 열리지 않습니다.
- 예전에 3000, 5000, 5001 을 열어 둔 규칙이 있으면 **지웁니다.**
- 공유기의 UPnP 자동 포트 열기는 끄는 것을 권장합니다. DSM → 제어판 → 외부 액세스 → 라우터 구성에서도 자동 설정하지 않습니다.

## 3. HTTPS 인증서 (Let's Encrypt)

DSM → **제어판 → 보안 → 인증서**

1. **추가 → 새 인증서 추가 → Let's Encrypt에서 인증서 얻기**
2. 도메인 이름 `alphy.devsean.me`, 이메일 입력 → 완료
   - 실패하면: 2단계 포트 80 포워딩, 1단계 DNS 를 다시 확인
3. 갱신은 DSM 이 자동으로 합니다.

## 4. 역방향 프록시

DSM → **제어판 → 로그인 포털 → 고급 → 역방향 프록시 → 생성**

| 항목 | 값 |
|---|---|
| 설명 | `alphy` |
| 소스 프로토콜 | `HTTPS` |
| 소스 호스트 이름 | `alphy.devsean.me` |
| 소스 포트 | `443` |
| **HSTS 활성화** | ✔ 체크 |
| 대상 프로토콜 | `HTTP` |
| 대상 호스트 이름 | `localhost` |
| 대상 포트 | `3000` |

- **사용자 지정 머리글** 탭 → 생성 → `X-Real-IP` = `$remote_addr`, `X-Forwarded-Proto` = `$scheme` 두 줄 추가
  (알피가 접속자 주소를 정확히 알아야 주소별 로그인 잠금과 로그인 기록이 제대로 동작합니다)
- **고급 설정** 탭 → 프록시 연결·전송·읽기 시간 제한을 `300` 초로 (종목을 많이 잡으면 첫 시세 수집이 1분 넘게 걸림)
- 저장 후 **제어판 → 보안 → 인증서 → 설정**에서 서비스 `alphy.devsean.me` 에 3단계 인증서를 지정

## 5. DSM 방화벽

DSM → **제어판 → 보안 → 방화벽** → 방화벽 활성화 → 프로필 **규칙 편집**. 위에서부터 순서대로:

| 순서 | 포트 | 소스 IP | 동작 |
|---|---|---|---|
| 1 | 모두 | 서브넷 `192.168.0.0` / `255.255.255.0` (집 네트워크) | 허용 |
| 2 | 사용자 지정 TCP `80,443` | 위치: **대한민국** | 허용 |
| 3 | (아래 "규칙이 일치하지 않으면") | | **거부** |

- 1번을 꼭 먼저 만드세요. 순서를 틀리면 집 안에서도 DSM 에 못 들어갈 수 있습니다.
- 집 네트워크 대역은 공유기마다 다릅니다(ipTIME 은 보통 `192.168.0.x`). PC 의 IP 를 보고 맞추세요.
- 해외에 나가 있을 때 접속하려면 2번에 그 나라를 추가하거나 잠시 "모든 위치"로 바꿉니다.

## 6. DSM 계정 보호 (알피와 별개로 NAS 자체)

- **제어판 → 보안 → 보호 → 자동 차단** 사용 (예: 5분 안에 5번 실패 시 차단)
- 오른쪽 위 사람 아이콘 → **개인 → 보안 → 2단계 인증** 켜기
- **제어판 → 사용자 및 그룹**: 기본 `admin` 계정은 비활성화
- **제어판 → 외부 액세스 → QuickConnect**: 쓰지 않으면 끄기
- **제어판 → 업데이트 및 복원**: DSM 보안 업데이트 자동 설치

## 7. 확인

휴대폰 **Wi-Fi 를 끄고(LTE/5G)**:

- [ ] `https://alphy.devsean.me` → 주소창 자물쇠, 알피 로그인 화면
- [ ] 로그인할 때 비밀번호 + 인증 앱 코드를 물어봄
- [ ] 설정 → 보안 → 최근 로그인 기록의 주소가 **휴대폰의 공인 IP** 로 찍힘
      (`127.0.0.1` 이나 `172.x.x.x` 로 나오면 4단계 사용자 지정 머리글을 다시 확인)
- [ ] `http://집공인IP:3000`, `https://집공인IP:5001` 은 **열리지 않아야** 정상

## 평소 습관

- 설정 → 보안의 **최근 로그인 기록**을 가끔 확인. 모르는 주소의 "로그인"이 있으면 비밀번호 변경 → 모든 기기 로그아웃
- 실전 주문을 쓰기 전까지 `.env` 의 `KIS_ALLOW_REAL_ORDERS` 는 비워 둠
- 휴대폰을 잃어버렸으면 File Station 으로 `docker/alphy/nas/cache/config` 에 빈 `disable-2fa.txt` 파일을 올리면 2단계 인증이 꺼집니다. 로그인 후 다시 켜세요
- GitHub 계정(bw1213)에 2단계 인증 필수: main 에 들어간 코드는 Watchtower 가 NAS 에 자동으로 깔기 때문에 GitHub 계정이 곧 NAS 의 열쇠입니다
- `docker/alphy/nas/cache/config` 폴더는 Hyper Backup 등으로 백업 (앱키·비밀번호 해시가 들어 있음, 백업도 암호화 권장)

## 다른 방법

| 방법 | 장점 | 단점 |
|---|---|---|
| **역방향 프록시 (이 문서)** | 도메인으로 어디서나 접속, DSM 기본 기능만 사용 | 443/80 포트를 열어야 함 |
| Cloudflare Tunnel | 포트를 하나도 안 열고 집 IP 도 숨김 | `devsean.me` DNS 가 Cloudflare 에 있어야 하고, 터널 컨테이너를 하나 더 띄움 |
| Tailscale / VPN | 가장 안전 (나만 접속) | 접속할 기기마다 앱 설치, 도메인 주소로는 못 씀 |
